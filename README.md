## Exercise notebook

`Exercise.ipynb` is a CNN analysis and custom implementation exercise in PyTorch:

1. Analyse the AlexNet and ResNet-18 architectures and how well they suit medical images.
2. Design a custom CNN (`PneumoniaCNN`) for grayscale chest X-rays.
3. Load the chest X-ray pneumonia dataset from Kaggle with `kagglehub`.
4. Train the model with Adam and a learning-rate scheduler.
5. Discuss why batch normalisation helps when training deep networks.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Siva-Subramaniam-DS/AS400-Certification-/blob/main/Exercise.ipynb)

### Run it locally

```bash
pip install torch torchvision kagglehub
```

Then open `Exercise.ipynb` in Jupyter or VS Code and run the cells in order.
